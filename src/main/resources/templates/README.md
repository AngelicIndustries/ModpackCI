# My Modpack

Minecraft 1.7.10 modpack built with [ModpackCI](https://github.com/AngelicIndustries/ModpackCI).

```sh
./modpackw runClient     # play it on Java 8 (runClient25 for Java 25)
./modpackw packwiz help  # manage mods with packwiz
./modpackw help          # everything else
```

On Windows, use `modpackw.bat`.
